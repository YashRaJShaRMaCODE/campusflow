# Security policy

CampusFlow contains student-data API examples. Never put real student names, marks, school records, credentials, or exports in a public issue or reproduction. Use synthetic records only.

If private vulnerability reporting is enabled for this repository, use **Report a vulnerability** in GitHub's Security tab. Otherwise, contact the repository owner through the public GitHub profile. Include the affected version, impact, and a minimal reproduction with synthetic data.

There is no published response-time guarantee. Revoke exposed Django, database, hosting, or LeadHub credentials and rotate them in the owner-controlled provider. Do not use this sample with real student records before a qualified privacy/security review and written school agreement.
